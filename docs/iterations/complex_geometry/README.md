**Question:** Can complex geometry bypass a physical fold and return to a
useful real stationary shape?

**Result:** Partly supported. Local loop transport works; two-loop restoration
error is 7.64e-14. Real pseudo-arclength also crosses the fold. At t=1, 0/3
fixed detours return real, despite half-step agreement below 4.45e-16.
The subsequent 92 directed loop tests also return no real endpoint.

**Why:** A loop changes the stationary-solution branch. The local exchange
turns a minimum into a maximum; wider detours reach the same nonreal endpoint.
The exact local fold derivation predicts the exchange. Endpoint agreement
does not establish equal winding or path classes.

**Limit:** Fixed-center radius family with deliberately mismatched center;
no unrestricted inverse recovery claim.

**Decision:** Retain the qualified mechanism and close these route families.
The 46 tested generators act only within the observed complex pair; their
compositions cannot escape it under that numerical action model. A further
study must investigate different generators, such as complex critical
values or different attachment paths. Literature supplies no automatic
real-return guarantee for this high-contrast instrument.
