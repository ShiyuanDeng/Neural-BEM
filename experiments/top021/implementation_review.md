# TOP-021 owner implementation review

Owner/reviewer: Codex `/root`; no independent review claimed.

The suite preserves the twelve-scene specification and original observations.
Only missing added training columns are generated, using the existing analytic
oracle and original 256/512 convergence check. Three expanded records are reused
byte-for-byte with their measured qualification evidence. A verified TOP-020
recovery and current source-bound mocked tests are required before this work.

Each isolated scene process computes H once, then S and F sequentially. The
common prefix is charged once in actual campaign work and in full in each arm's
standalone cost. The controller does not receive truth/count information. The
capacity rule depends on its returned count, is shared across arms and is under
qualification here. All geometry is preserved by exact zero padding.

Existing prefix, FD LM, gauge, feasible set, tolerances and quota semantics are
reused. No shared numerical source/default changes. A qualified S stage-1
endpoint is required to run F; its identical stage-1 endpoint is required before
F stage 2. Later S failure cannot select F's trajectory. All four prescribed
stages remain mandatory for full recovery qualification.

Per-phase ledgers reserve batches and install hard wall timers. The campaign
caps four single-thread subprocesses and enforces a four-hour wall watchdog.
The sum of declared per-scene and oracle caps is 240,360 charged calls. A killed
worker retains available checkpoints and its work is labelled a lower bound.
Refused geometry calls remain distinct from completed BIE systems.

Every original scene retains both arm rows, including prefix failures and arms
not released by a shared numerical gate. Final/retained states are selected by
recorded execution order, never truth score. Geometric reporting is performed
with a zero-call physical ledger, so accidental physical scoring fails closed.
Saved complex predictions, endpoint/state/gradient associations, acceptance
margins, monotonicity and counts are replayed independently before conclusions.

New experiment sources and all imported experiment dependencies are copied into
the bundle; measured source/input hashes remain frozen. Physical dispatch is
conditional on TOP-020 PASS even though preparation started while it ran.

Full qualification requires all candidate recovery gates and no required
regression. A completed failed row is evidence to diagnose, not a reason to
change gates or claim general recovery. No production default promotion is part
of this suite driver.
