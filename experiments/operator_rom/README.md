# Operator-ROM landscape screen

See the [joint assessment](../../results/experiments/outsider_research_20260916/README.md). These are controlled depth slices of a scalar wave problem, not a full electromagnetic imaging benchmark.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONPATH=solvers:.
python -m experiments.operator_rom.screen
python -m experiments.operator_rom.fixed_projection
python -m experiments.operator_rom.qualify
python -m pytest -q experiments/operator_rom/test_rom.py
```

`screen` generates wave data and retains an initial moving-basis experiment. That initial objective is **not** the published regularized inversion objective. `fixed_projection` implements the observed-data projection and frozen basis from Appendix E of [Borcea et al., Waveform inversion via reduced order modeling](https://josselin-garnier.org/wp-content/uploads/2022/10/geophysics22.pdf). Only the fixed-projection results support the final assessment. `qualify` adds band-limited symmetric noise, selects rank from its known perturbation norm, and tests a finer grid with four sources. Its synthetic knowledge of the noise norm is a favourable assumption.

The basin metric is the fraction of 55 sampled starting depths that descend to the true depth by successive lower-valued neighbours. It is not a recovery probability for full FWI. Retained JSON includes rank-dependent failures; do not silently drop them. NPZ caches are regenerated by `screen`.
